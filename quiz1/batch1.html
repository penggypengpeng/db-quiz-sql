6 Independent Database Challenges

Navigate using the arrow keys

Available Tables: Authors, Books, Members, Loans

Problem 1

Task: Create a new table.

Write a SQL query to create a table named Publishers. The table should have the following columns:

  • publisher_id (Integer, Primary Key)
  • name (Variable character up to 100 length)
  • city (Variable character up to 50 length)

Problem 2

Task: Filter and Sort.

Write a SQL query to select the title and publish_year from the Books table where the publish year is between 1990 and 2000.

Order the final results by publish_year in descending order.

Problem 3

Task: Combine Tables.

Write a SQL query to retrieve a list of all book titles alongside the names of the authors who wrote them.

Your result set should display the title from the Books table and the name from the Authors table.

Problem 4

Task: Aggregation and Sorting.

Write a SQL query to calculate the average price of books written by each author.

Display the author_id and the calculated average price. Order the results by the average price from highest to lowest.

Problem 5

Task: Filter against an aggregate.

Write a SQL query to find the title and price of all books that cost strictly more than the overall average price of all books in the database.

Note: You must use a subquery to solve this problem!

Problem 6

Task: Data Modification.

A new member has just joined the library.

Write a SQL query to INSERT the following record into the Members table:

  • member_id: 9999
  • name: 'Jane Doe'
  • join_date: '2023-10-01'
  • status: 'Active'
