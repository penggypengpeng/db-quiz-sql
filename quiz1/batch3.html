SQL Problems Batch 3

University Database Challenges

Navigate using the arrow keys

Available Tables: Departments, Students, Courses, Enrollments

Problem 1

Task: DDL Table Creation.

Write a SQL query to create a new table named Professors with the following specifications:

  • professor_id (Integer, Primary Key)
  • first_name (up to 50 length)
  • last_name (up to 50 length)
  • department_id (Integer, Foreign Key referencing Departments)
  • hire_date (Date)

Problem 2

Task: Range Filtering and Sorting.

Write a SQL query to select the first_name, last_name, and gpa from the Students table for all students whose GPA is from 3.00 to 4.00.

Order the final results by gpa in descending order.

Problem 3

Task: Multi-Table Join.

Write a SQL query to retrieve a list of all course names along with their respective department names.

Display the course_name from the Courses table and the department_name from the Departments table.

Problem 4

Task: Aggregation and Grouping.

Write a SQL query to calculate the average course fee for each department.

Select the department_id and the calculated average fee from the Courses table. Order the results by the average fee from highest to lowest.

Problem 5

Task: Subquery Filtering.

Write a SQL query to find the first_name, last_name, and gpa of all students who have a GPA higher than the overall average GPA of all students in the database.

Note: Subquerying is required to solve this problem!

Problem 6

Task: Data Removal.

An administrator needs to purge failing records from the active enrollment records.

Write a SQL query to DELETE all records from the Enrollments table where the grade is equal to 'F'.
