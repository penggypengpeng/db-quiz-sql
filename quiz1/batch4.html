SQL Problems Batch 4

Healthcare Database Challenges

Navigate using the arrow keys

Available Tables: Doctors, Patients, Appointments, Prescriptions

Problem 1

Task: DDL Table Creation.

Write a SQL query to create a new table named Rooms with the following specifications:

  • room_id (Integer, Primary Key)
  • room_number (String up to 10 length)
  • floor (Integer)
  • status (String up to 20 length)

Problem 2

Task: Range Filtering and Sorting.

Write a SQL query to select the appointment_id, appointment_date, and fee from the Appointments table for all appointments with a fee from 100.00 to 250.00.

Order the results by fee in descending order.

Problem 3

Task: Multi-Table Join.

Write a SQL query to retrieve a list of all appointment dates alongside the full names of the patients who attended them.

Display the appointment_date from the Appointments table and the first_name and last_name from the Patients table.

Problem 4

Task: Aggregation and Grouping.

Write a SQL query to calculate the total fee revenue generated by each doctor using SUM.

Select the doctor_id and the calculated total sum of fee from the Appointments table. Order the results by total fee revenue from highest to lowest.

Problem 5

Task: Subquery Filtering.

Write a SQL query to find the appointment_id of all appointments which have a fee higher than the overall average appointment fee.

Note: Subquerying is required to solve this problem!

Problem 6

Task: Data Modification.

Dr. Meredith Grey (doctor_id = 3) updated her consultation rates.

Write a SQL query to increase the fee by 15% for all records in the Appointments table where the doctor_id is equal to 3.
