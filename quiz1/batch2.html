SQL Problems Batch 2

Database Assessment Series

Navigate using the arrow keys

Available Tables: Customers, Categories, Products, Orders

Problem 1

Task: DDL Table Creation.

Write a SQL query to create a table named Reviews with the following schema:

  • review_id (Integer, Primary Key)
  • product_id (Integer, Foreign Key referencing Products)
  • rating (Integer)
  • comment_text (Variable character up to 255 length)

Problem 2

Task: Pattern Matching and Sorting.

Write a SQL query to select the product_name and price from the Products table for all products whose name contains the word 'Board' or 'Chair' using a pattern match (LIKE).

Order the results by price in descending order.

Problem 3

Task: Relational Join.

Write a SQL query to retrieve all product names alongside their respective category names.

Display the product_name from the Products table and the category_name from the Categories table.

Problem 4

Task: Aggregation and Ranking.

Write a SQL query to find the total money spent by each customer across all their orders.

Display the customer_id and the calculated total sum of total_amount. Order the final output by the total sum from highest to lowest.

Problem 5

Task: Subquery Filtering.

Write a SQL query to retrieve the first_name and last_name of all customers who have placed an order with a total_amount greater than the average total order amount.

Note: Subquerying is required to solve this problem!

Problem 6

Task: Data Modification.

A storewide sale gives a discount to all items in category 1.

Write a SQL query using UPDATE to reduce the price of all products in the Products table by 10% where the category_id is equal to 1.
