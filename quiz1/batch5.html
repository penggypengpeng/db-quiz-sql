SQL Problems Batch 5

Fitness Center Database Challenges

Navigate using the arrow keys

Available Tables: Trainers, Members, Classes, Bookings

Problem 1

Task: DDL Table Creation.

Write a SQL query to create a new table named Equipment with the following specifications:

  • equipment_id (Integer, Primary Key)
  • equipment_name (String up to 100 length)
  • category (String up to 50 length)
  • purchase_date (Date)

Problem 2

Task: Pattern Matching and Sorting.

Write a SQL query to select the name, membership_tier, and email from the Members table for all members whose email domain ends with '@gmail.com'.

Order the results by name in ascending alphabetical order.

Problem 3

Task: Multi-Table Join.

Write a SQL query to retrieve a list of all class names alongside the names of the trainers teaching them.

Display the class_name from the Classes table and the name from the Trainers table.

Problem 4

Task: Aggregation and Grouping.

Write a SQL query to calculate the total number of bookings made for each class.

Select the class_id and the calculated total count of bookings from the Bookings table. Order the results by the total count from highest to lowest.

Problem 5

Task: Subquery Filtering.

Write a SQL query to find the class_name and fee of all classes that cost strictly more than the overall average class fee.

Note: Subquerying is required to solve this problem!

Problem 6

Task: Data Removal.

The system needs to clear out all cancelled class bookings.

Write a SQL query to remove all records from the Bookings table where the attendance_status is equal to 'Cancelled'.
